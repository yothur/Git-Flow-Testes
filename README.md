git clone -> clona o repositório
git add . (ou nome do arquivo) -> adiciona o arquivo em um estado de preparação para ser salvo
git commit -m "algumamensagem" -> salva as alterações dentro do repositório local
git push | git push -u origin nomedabranch | git push origin nomedabranch -> envia as alterações para o github em uma determinada branch
git checkout -> troca pra uma branch
git branch -M nomedabranch -> cria uma branch nova sem ir direto pra ela
git checkout -b nomedabranh -> cria uma nova branch e ja troca pra ela
git commit --amend -m "algumamensagem"-> substitui o commit aanterior
git status -> verifica a atual situação do git, se precisa está tudo ok, se algo precisa ser adicionado ou se algo está pronto
